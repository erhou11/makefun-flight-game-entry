Kestrel Post: Valley Air Mail - a complete flight game in the browser. Take off from Kestrel Strip in the Kestrel K-2 mail plane, thread eight gold rings over a patchwork valley, drop mail parcels on the farm targets, then land back home before the fuel runs out. Chase and cockpit cameras, airspeed and altitude tapes, compass, artificial horizon, fuel and damage gauges, generated engine sound, and an autopilot demo behind the title screen. Static files only: no build step, no downloads, no network.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in a desktop browser
```
